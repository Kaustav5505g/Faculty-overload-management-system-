# Faculty Workload Management System

A Java-based system for managing faculty workload data, assignments, and related academic records.

## Technology Stack

- Java JDK 17+
- JDBC for database connectivity
- SQL for relational data management
- MVC architecture
- DAO pattern for persistence and database access

## Project Structure

```text
src/
└── com/
    └── system/
        ├── model/
        ├── dao/
        └── service/
sql/
```
